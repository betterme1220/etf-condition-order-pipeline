# etf-condition-order-pipeline

平安证券 ETF 条件单半自动框架。

核心定位：人工审核主导、券商 APP 条件单执行、系统负责计算、风控、证据留存与盘后对账。

## 安全原则

最终硬红线以 `config/safety_limits.py` 为准，YAML 只能更严格，不能更宽松。

## 隐私原则

以下内容不得上传 GitHub：

- 持仓 Excel
- 券商导出 CSV
- 人工审核表
- 条件单截图
- 成交截图
- 对账报告
- 日志
- Hash 清单
- 任何包含账户、资金、持仓、交易记录的数据文件

相关目录和文件类型已写入 `.gitignore`。

## 当前执行边界

- 只做场内 ETF
- 只做高卖低买
- 不做融资融券
- 不做非 ETF
- 不做盘后交易
- 永远需要人工确认
- 未完成券商模板校准前，不允许实盘自动下单
